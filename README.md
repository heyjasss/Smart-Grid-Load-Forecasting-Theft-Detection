# Smart Grid Load Forecasting and Theft Detection

## Project Overview
This project focuses on smart grid energy monitoring, load forecasting, and electricity theft detection using IoT-based sensors and data analysis techniques.

## Technologies Used
- ESP32 Microcontroller
- PZEM Energy Monitoring Module
- Current Transformer (CT) Sensor
- Python
- IoT and Energy Monitoring
- Machine Learning

## Project Objectives
- Monitor electricity consumption using energy monitoring sensors.
- Collect and analyze electrical load data.
- Identify abnormal electricity consumption patterns.
- Explore electricity theft detection techniques.
- Support efficient and reliable energy monitoring.

## Project Features
- Sensor-based energy monitoring.
- Electrical load data collection.
- Load forecasting and analysis.
- Abnormal consumption detection.
- Smart grid monitoring dashboard.

## Project Workflow
1. Collect electrical data using sensors.
2. Process and analyze the collected data.
3. Monitor electricity consumption patterns.
4. Detect abnormal readings.
5. Analyze load forecasting and theft detection results.

## Applications
- Smart energy monitoring
- Electricity consumption analysis
- Smart grid management
- Electricity theft detection
